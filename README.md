# 🏡 Real Estate Price Estimation using Machine Learning

## 📖 Project Overview

The **Real Estate Price Estimation System** is a Machine Learning web application that predicts property prices based on key housing features such as area, number of bedrooms, bathrooms, parking availability, and other important parameters.

The project combines **Machine Learning**, **Flask**, and a simple web interface to provide fast and accurate house price predictions.

---

# 🚀 Features

✅ Predict house prices instantly

✅ Machine Learning based prediction

✅ User-friendly web interface

✅ Fast response time

✅ Clean and responsive design

✅ Accurate prediction model

✅ Easy deployment using Flask

# ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/gawadeomkar0516/Real-Estate-Price-Estimation-main.git
```

### Navigate

```bash
cd Real-Estate-Price-Estimation-main
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
python app.py
```
